# MobiLoop MCP v0.1.0-alpha.10

Pre-release published on 2026-09-23.

## Highlights

- Added secure-by-default configuration, approval enforcement, artifact redaction, path escape protection, and deterministic `security.*` tools.
- Hardened Docker security scans with a non-root, read-only source mount and a separate tmpfs evidence mount.
- Added direct W3C Appium capability support and regression coverage.
- Validated a real Appium 3 and UiAutomator2 session against an installed Android application on Genymotion Galaxy S24, collecting screenshot and XML evidence without changing app data.
- Added GitHub Pages deployment, static-site metadata validation, canonical metadata, sitemap, robots directives, Open Graph, Twitter card, and JSON-LD source-code metadata.

## Verification

- `npm test`: 56 passing tests.
- Lint, TypeScript typecheck, formatting, package dry run, and high-severity dependency audit passed.
- Docker image builds successfully and the read-only security MCP scan writes artifacts only to its dedicated tmpfs mount.
- GitHub Actions `Validate` and CodeQL passed on the release candidate.
